## 给写计划的人

1. 新计划放在本目录根，文件名用 `YYYY-MM-DD-短名.md`，并在 `../README.md` 登记状态。
2. 完成时把文件移进 `completed/`，在文件头补一行“完成时间 + 证据（报告或提交）”。
   本项目的复选框只在真人复核后才勾，**空复选框不代表没做完**，状态以文件头和索引为准。
3. 被取代时移进 `archive/`，在文件头写清“被谁取代”。彻底无价值的直接删除，不必留档。
