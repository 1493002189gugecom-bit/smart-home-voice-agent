| 指标 | 结果 |
| --- | --- |
| 符合预期 | 24/24 |
| 误触发 | 0 |
| 服务异常 | 0 |
| 判断耗时中位数 | 844毫秒 |
| P95 | 1015毫秒 |

这组样例不能代表开放家庭环境的准确率。报告位于 `output/voice-evaluation/2026-10-22-intent.json`，只有内置文本、预测结果和耗时，没有密钥或录音。

固定测试句通过 Edge 分两段输出到当前 HyperX 耳机：音频共5.71秒，约2.55秒打开首次输出流，PortAudio播放完成。这是输出接口证据，尚无听者确认或麦克风测量的可闻延迟。

重载后语音健康状态为 `listening / hybrid`，`audio_processing=ready`，`asr_provider=local`，`tts_provider=edge`。
控制台实际代理的“停止回复”接口通过；单句“这碗汤好热啊”实际API试判为 `ignore`，耗时859毫秒。
