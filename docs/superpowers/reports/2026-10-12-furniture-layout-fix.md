# 家具布局与朝向修正

2026-10-12：修正已进入实际网页与 Android 2.1.1（versionCode 4）。自动空间检查和浏览器模拟回归通过，观感与真实平板安装/性能仍待用户验收。

## 问题与修正

原因是素材的原生方向与摆放坐标没有按房间墙体核对：房间后墙在局部 +Z，KayKit 床头在原生 -Z，座椅/抽屉/厨房门与控制面朝原生 +Z。仅缩放和居中不足以保证合理布局。

| 原问题 | 当前摆放 |
| --- | --- |
| 床头朝远离后墙方向，床整体离墙较远 | 床旋转 180°并移近后墙，床头靠墙，床脚朝房间内部；床头柜移至床头侧 |
| 厨房柜门、灶台控制面朝墙，冰箱与灶台实体重叠 | 橱柜、水槽、灶台与冰箱朝操作通道，背部沿后墙对齐；冰箱与灶台分开 |
| 餐椅背向桌子 | 两张餐椅面朝桌面，桌椅与工作台之间保留操作通道 |
| 右侧客厅柜门朝外，柜背无墙 | 柜体移至左墙，抽屉朝房间内部；卧室柜也贴近左墙 |
| 沙发离后墙较远，茶几位置不协调 | 沙发背靠后墙，茶几移近座位并落在地毯表面 |
| 卧室台灯悬空约 0.10，餐桌台灯悬空约 0.225 场景单位 | 台灯底面与床头柜/餐桌顶面相接 |
| 挂画正面朝外、穿墙且超过墙顶 | 缩小挂画，正面朝室内，挂于空调侧边，低于墙顶并不穿墙 |
| 默认镜头穿过后墙看到家具背面 | 从 +X/-Z 的开敞一侧看入，直接看到家具及操作面 |

客厅柜体原本没有越出地板；初查时的越界判断经实际包围盒检查更正。真正越墙的是挂画，实体重叠的是冰箱与灶台。

改动集中在 `web/src/home-furniture.ts` 的家具坐标/朝向和 `web/src/home-scene.ts` 的默认相机位置。模型加载、共享图集、设备确认状态、远景隐藏标签及近景渐显继续使用现有实现。床头与后墙内侧间距约 0.087、厨房操作通道约 0.576，均为**示意场景单位**，不作为真实住宅测量或建筑合规尺寸。
