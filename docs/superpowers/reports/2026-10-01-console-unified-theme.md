# 终端六页统一“我的家”视觉风格

状态：已实现、已构建、浏览器显示检查通过；整体观感待用户评价。

## 用户要求与原因

用户要求电脑 `8770` 的总览、视觉、语音、身份和服务页与“我的家”保持相同排版风格。原来 `App.tsx` 仅在 home 页启用 `home-mode`，导致导航栏在 214px 与 248px 间变化，且其他页面仍使用浅色卡片和绿色按钮。

## 已修改

- 六页统一使用深色外壳和自适应导航；同宽度下标题坐标、内容边距、字号一致，含横屏低高度时的紧凑布局。
- 新增集中样式 `web/src/console-theme.css`，统一深蓝渐变背景、深蓝卡片、暖金按钮、输入框、状态提示、对话气泡和焦点边框。次要动作、删除动作、在线/离线仍有明确区分。
- 身份卡片在中等屏幕显示两列，窄屏一列，减少按钮文本挤压。
- 采用现有“我的家”主题作为视觉依据。UI/UX 技能的辅助脚本路径缺失，使用其文档检查项完成一致性检查。

## 验证证据

- `node --experimental-strip-types --test src/*.test.mjs`：23 项通过。
- `npm.cmd run android:build`：TypeScript、Vite、Capacitor 同步及 Gradle debug 构建通过；通过 USB 覆盖更新现有平板包。
- 在真实电脑终端逐页查看总览、视觉、语音、身份、服务。没有启动摄像头、录入身份、更改音频设备或写入设备状态。
- 浏览器临时模拟 1280×800、1024×800、768×800，六页均无页面横向溢出，且每组标题坐标一致。1280 宽下导航栏均为 214px、标题坐标约 `(252,52)`；1024 下约 `(31,118)`；768 下约 `(20,125)`。验证后恢复视口。
- 本地截图：`runtime/perception/console-unified-theme.jpg`。已刷新新建的电脑终端预览页至总览。
- `git diff --check` 通过。功能测试证明既有前端逻辑无回归，不代表摄像头注册、语音打断或设备性能通过真人验收。

## 使用

电脑打开 `http://127.0.0.1:8770/`，刷新后逐个切换页面。若浏览器仍缓存旧浅色页面，按 Ctrl+F5 强制刷新。Android 当前只提供“我的家”入口；电脑其他功能页面未因此开放给平板。
